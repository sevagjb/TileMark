More options

Restore

Replaces all your current links and groups with the ones from a backup file (older backups work too). Your account and other people's links stay as they are.

People

Everyone has their own links, groups, API key and backups. Nobody, the admin included, can see someone else's links.

Installation

Off by default. When on, anyone with an account can make TileMark open pages inside your network. Turn it on only if you trust everyone with an account. Local links can always be saved; without this they show only their address.

Restore the whole installation

Daily backups hold every account. Restoring one puts the whole installation back to that day; everyone signs in again afterwards. A safety copy of the current state is made first and listed here as "before restore", so a restore can be undone.

Your recovery key. It opens every encrypted backup when no admin password works, for example on a new server or after a forgotten password. Save it somewhere safe now (a password manager, or printed); it is not shown again.

Home Assistant sensors

Shows TileMark in Home Assistant as a device with sensors for the number of links and broken links (all accounts together, counts only) and the time of the last weekly check, plus an event when that check finishes, for a notification. Works through MQTT; Home Assistant needs its MQTT integration.

Leave the broker empty to use Home Assistant's own MQTT broker.


Two TileMarks with the same ID (for example after copying the database) show up in Home Assistant as one device. Give one of them a new ID.
